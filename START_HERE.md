##  CONSEILS UTILES

1. **Sauvegarde complète** (Full) = Première fois, tous les fichiers
2. **Sauvegarde différentielle** (Diff) = Mises à jour, fichiers modifiés
3. **Config stockée** automatiquement dans `%ProgramData%\EasySave\`
4. **Logs disponibles** dans `logs/` pour historique
5. **Langue** = Configurable (EN/FR par défaut)
