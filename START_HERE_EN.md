##  USEFUL TIPS

1. **Full backup** = First time, all files
2. **Diff backup** = Updates, modified files only
3. **Config stored** automatically in `%ProgramData%\EasySave\`
4. **Logs available** in `logs/` for history
5. **Language** = Configurable (EN/FR by default)
